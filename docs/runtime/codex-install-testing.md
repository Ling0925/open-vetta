# 原会话 Codex 后端测试安装说明

这是工程测试包，不是完整验收后的稳定版。请核对制品所标的源码提交和 SHA256SUMS。
当前支持 Apple Silicon / Intel Mac 和 Windows x64。包内包含固定版本 Codex 0.157.0，
不需要额外安装 Node、Bun 或 Codex。测试包未签名/未公证，系统可能提示来源警告；不要全局关闭系统安全保护。

## 安装与数据

先完全退出原 Vetta，备份原应用及数据目录（默认 ~/.vetta），不要同时运行正式版和测试版。
macOS 解压制品后使用 DMG 或应用 ZIP，放到固定安装位置再启动；Windows 解压完整应用 ZIP，运行其中 Vetta.exe。
本版本沿用原应用设置、凭据库和会话记录，并非整套数据隔离。Codex 自身执行数据放在独立托管目录。

## 使用方式

打开原来的新会话或已有会话，在输入框工具栏的模型选择器旁点击 Native / Codex 开关。
切换仍留在同一个会话，不跳转独立预览页，不要求填写程序路径、版本或 Codex 登录目录。
选择已有 Responses 模型；网关地址、密钥、请求头和代理沿用原模型设置，不要求另行登录 ChatGPT。
第一条消息先确认后端再发送；后端或协议不可用时明确报错，不能偷偷回退 Native。

已有会话先结束当前任务和队列，再切换。Codex 使用工作区写入沙箱，额外权限仍在原权限抽屉逐项确认。
Native 的完全访问选择不会转成 Codex 完全访问。第一次测试请用专门的临时 Git 项目，先执行只读检查指令。

建议连续验证：Native 交流 → 切到 Codex → 询问先前内容 → 执行小任务 → 原停止按钮 → 新指令 →
切回 Native → 核对双方新产生的上下文 → 退出后重新打开同一条会话。
历史工具调用仅交接为记录，不会被重跑；停止不会回滚已经完成的文件修改。

## 当前范围

支持本地普通会话的文本和 Codex 原生工具。远程项目、团队、独立 Agent 权限档案、Native 计划模式及
Native 附件/插件注入暂未接通，不能把不可用能力当作已经兼容。
模型需要明确配置为 openai-responses。网关需要 HTTPS，只有本机回环地址允许 HTTP。
切换不迁移模型隐状态。每轮 Codex 使用独占线程和文本历史交接，长历史会增加启动/输入成本；
超过有界交接上限会明确失败，不静默删掉旧上下文。

安装包构建成功、工具栏冒烟测试、真实协议/工具测试和完整质量检查是不同门禁，结果以对应提交的 CI 为准。
切勿把旧独立预览包或基线已通过的测试当成本版本已验收。真实网关仍需用户本地联调。
报错时提供操作顺序、截图和错误码，隐藏真实密钥、内部地址和敏感业务内容。
